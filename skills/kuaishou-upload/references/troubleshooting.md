# Troubleshooting

## `sau` command not found

Try the following:

```powershell
.\.venv\Scripts\Activate.ps1
sau kuaishou --help
```

```powershell
.\.venv\Scripts\sau.exe kuaishou --help
```

```bash
uv run sau kuaishou --help
```

If the project is not installed in the current environment yet:

```bash
uv pip install -e .
```

## Cookie invalid or expired

Check the cookie state first:

```bash
sau kuaishou check --account <account>
```

If it is invalid, log in again:

```bash
sau kuaishou login --account <account>
```

## Login QR code problems

If the user reports that the QR code is hard to scan in the terminal:

- Prefer the local QR code image generated by the CLI / uploader first
- Switch to `--headed` only if the user explicitly needs a visible browser window or the image approach is still inconvenient
- If the CLI / uploader has already generated a temporary QR code image, the agent should not reply with only the image path
- The agent should show or send the local QR code image to the user to scan
- The image path is only supplementary information

## Missing upload arguments

### Video upload

At minimum:

- `--account`
- `--file`
- `--title`

### Image post upload

At minimum:

- `--account`
- `--images`
- `--title`

`--note` is currently the optional image post body.

## Only one image takes effect in an image post upload

If the user passed several images at once but the page recognized only one, first check:

- Whether the files passed to `--images` are really different files
- That it is not the same path repeated several times

## Scheduled publishing

Use this time format:

```text
YYYY-MM-DD HH:MM
```

If you do not need scheduled publishing, remove `--schedule` to publish immediately.
